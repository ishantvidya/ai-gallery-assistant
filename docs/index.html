Private by architecture

🔒 Photos never leave the phone

There is no server. All AI inference happens on-device with ONNX Runtime — the app has no network permission at all.

⚡ Works offline

The app has no network permission at all. Once photos are indexed, browsing works with airplane mode on. Semantic search unlocks once the CLIP model is on the device.

🧠 Real CLIP intelligence

A quantized CLIP vision-language model understands scenes, objects and concepts — not just filenames.

🆓 Free & open source

No accounts, no ads, no telemetry. Source code is public.

Install in 4 steps

  1. Download the APK using the button above.
  2. Open it. Android will warn about installing from your browser — tap “Install anyway” (this appears because the app isn’t from a store).
  3. Open the app and allow photo access. Your gallery is indexed on the phone (names, albums, dates) in seconds.
  4. Browse the grid. Semantic “describe it to find it” search activates once the CLIP model is provisioned on the device (developer setup for now).

Updating: download the new APK and install it over the old version — your data stays.

Why sideload instead of Play Store?

Distribution through GitHub keeps the app fully free and independent: no store review delays, no developer fees, and identical privacy guarantees. The tradeoff is the one-time “unknown sources” warning on install.
